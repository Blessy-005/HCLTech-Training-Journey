## Development Approach

The project was developed incrementally using feature-based commits.

- Documentation and project setup were committed first.
- Database entities and migrations were added.
- Each API module was implemented and committed separately.
- Validation and booking workflows were hardened in a later commit.
- Documentation and final API testing are maintained as separate completion tasks.

## Commit Convention

The project uses Conventional Commit-style messages:

- `feat:` New functionality
- `fix:` Bug fixes and improvements
- `docs:` Documentation changes
- `chore:` Configuration and maintenance changes
