# LINQ Mastery Practice Project

This is a student starter project for practising LINQ with C# and .NET 10.

## Requirements
- Visual Studio with the .NET desktop development workload, or another .NET 10-compatible C# IDE
- .NET 10 SDK

## Open and run
1. Extract the ZIP file.
2. Open `LinqMasteryPractice.csproj` in Visual Studio.
3. Build and run the project once.
4. Open `Program.cs`.
5. Uncomment one exercise method call inside `Main()`.
6. Implement the TODO comments and run your solution.
7. For each task, write both method syntax and query syntax wherever the syntax is supported naturally.

## Important practice rules
- Do not delete or change the sample data unless an exercise asks you to.
- Print results using `Console.WriteLine`, `foreach`, or `string.Join` as appropriate.
- For query syntax, it is normal to use method calls such as `Count()`, `Sum()`, `FirstOrDefault()`, `Distinct()`, `ToList()`, `ToDictionary()`, and `ToLookup()` after defining the query.
- Some operators do not have direct query-syntax equivalents. Learn where to combine query syntax with method calls.
- This is a practice scaffold: TODOs are intentionally incomplete.

## Topics
Filtering, projection, SelectMany, sorting, element operators, aggregation, Any/All, grouping, set operations, inner and left joins, GroupJoin, partitioning, nested queries, combined queries, dictionaries, lookups, and business reports.
